# 공통 AI연결앱 v1.15.0 배포

Character-Sheet-Maker 저장소의 변경 파일을 GitHub에 올리고 Vercel을 재배포한다. 이 폴더의 EXE도 일반 Git 파일로 함께 올린다. Vercel 빌드가 EXE를 공개 출력에 복사하고 사이트의 AI연결앱 설치·업데이트 링크를 연결한다.

처음 쓰는 사용자는 EXE를 실행해 공통 AI연결앱을 설치한다. 기존 사용자는 트레이에서 연결앱을 종료한 뒤 같은 EXE로 업데이트한다. 설치 후 사이트의 ChatGPT 연결을 누르고 트레이의 고급 연결 코드를 입력한다.
