# Character Sheet v0.6.1

프로젝트 루트에서 실행한다.

    node ./2026-11-12-Character-Sheet-v0.6.1/2026-11-12-server.mjs

http://127.0.0.1:43186/ 에 접속한다. Node.js, Python 3, ChatGPT 구독 연결용 Codex CLI가 필요하다. H3 원본 폴더를 프로젝트 루트에 둔다. 브릿지 모듈은 앱의 2026-11-12-bridge 폴더에 있다. 원본 H3 컴파일러는 ComfyUI 없이 실행된다.

H3 v1.3 프리셋 정의와 가이드 계산을 적용했다. 카드와 가이드의 마네킹은 Qwen 배포본의 MIT 고지 대상 PNG 7종이며 고지문과 라이선스를 함께 포함했다. 가이드 크기는 로컬 레이아웃 계산에 사용하고 생성 브릿지에는 가이드 치수를 명시한 프롬프트를 전달한다. 현재 생성 입력은 사용자 이미지 한 장이다.



UI 점검 기준은 Damir Sokolovsky (@heydamir)의 Unslop (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/)을 적용했다. https://heydamir.design/unslop


저장 버튼은 생성 결과를 원본 크기의 PNG로 저장한다.


기본 프리셋인 표준 3뷰는 정면2·전신 후면·얼굴 정면 순서다. 기존 전체 13뷰 프리셋은 기존 뷰 조합을 유지한다.

공개 주소 확정 후 OG 이미지 주소를 절대 URL로 바꾼다. Vercel Web Analytics를 활성화하면 HTTPS .vercel.app 주소에서 페이지 조회가 수집된다.
