앱으로 돌아가기

사용설명서

  1. AI연결앱 설치 또는 업데이트

    Windows에서 설치 파일을 실행하세요. 기존 연결앱을 업데이트할 때는 트레이에서 앱을 먼저 종료하세요.

    AI연결앱 설치 파일 받기

  2. ChatGPT 연결

    앱 화면에서 ChatGPT 연결을 누르세요. 브라우저가 앱 열기를 묻거나 AI연결앱이 사이트 주소 승인을 요청하면 확인하세요. 계정 로그인이 필요하면 ChatGPT 로그인 열기를 누르세요.

  3. 시트 생성

    8MB 이하의 PNG, JPEG 또는 WebP 이미지 한 장을 올리세요. 기본 표준 3뷰는 정면2, 전신 후면, 얼굴 정면 순서입니다. 원하는 뷰를 선택하고 시트 생성을 누르세요.

  4. 확대해서 확인하고 저장

    생성 결과를 클릭하면 크게 볼 수 있습니다. 저장을 누르면 원본 크기의 PNG를 받습니다.

연결이 안 될 때

공통 AI연결앱 v1.15.1 이상이 실행 중인지 확인하세요. 브라우저가 로컬 네트워크 접근을 요청하면 허용하세요.
